# TodoToggle 迭代记录

这份文档记录产品功能的演进，重点说明使用体验上的变化。

## 当前版本：1.0

TodoToggle 已从一个简单的桌面待办窗口，发展为面向课程作业管理的小助手。

### 已完成

- 支持手动添加、完成和删除待办。
- 支持将任务拖动排序，以安排优先级。
- 支持配置多个本地课程仓库。
- 支持扫描作业目录，并自动生成需要处理的作业待办。
- 支持将不需要的自动待办加入黑名单，避免重复出现。
- 支持查看扫描、同步和本地更新的最近结果。
- 支持一键完成“同步、更新、扫描”流程。
- 支持全局快捷键快速显示或隐藏窗口。
- 手动待办和自动待办都会将未完成事项自动置顶，已完成事项保留在列表下方。

## 使用体验的变化

早期版本只用于记录零散任务。现在，课程仓库中的作业目录可以直接转化为待办，减少了在文件夹、终端和待办软件之间来回切换的次数。

同步操作被拆分为单独按钮，同时也保留 `Sync All` 一键流程：需要确认每一步时可以分别执行；日常使用时则可以直接完成整套操作。

## 下一步可考虑的方向

- 为待办添加截止日期和提醒。
- 提供更清晰的仓库状态提示。
- 支持按课程或优先级筛选任务。
- 支持导出待办清单，便于备份或分享。
- 提供 Windows 版本的安装包。
