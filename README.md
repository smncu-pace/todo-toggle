# TodoToggle

TodoToggle 是一款面向课程作业场景的桌面待办工具。它把日常待办和本地作业仓库放在同一个轻量窗口里，帮助你更清楚地安排任务、同步作业仓库，并及时发现尚未完成的作业目录。

## 它能做什么

- 手动记录待办事项
- 自动扫描已配置的课程仓库，生成作业待办
- 将未完成事项自动置于列表顶部
- 拖动调整同一状态下任务的优先级
- 标记完成、删除完成事项，或将不需要的扫描结果加入忽略列表
- 一键同步远端仓库、更新本地文件并重新扫描
- 查看最近一次扫描和同步的结果
- 使用 `⌘ + T`（Windows 为 `Ctrl + T`）快速显示或隐藏窗口

## 适合谁

如果你的课程作业由 GitHub 仓库管理，并且需要定期把老师发布的新内容同步到自己的仓库，TodoToggle 可以把这套流程变得更集中：先同步，再更新本地，最后自动检查还有哪些作业需要处理。

## 开始使用

### 安装应用

在 macOS 上，打开 `dist` 目录中的 `.dmg` 安装包，将 TodoToggle 拖入“应用程序”文件夹即可。

也可以在项目目录中运行：

```bash
npm install
npm run dev
```

如需生成新的 macOS 安装包：

```bash
npm run dist:mac
```

### 首次设置

1. 打开 TodoToggle。
2. 在“课程作业扫描设置”中添加本地课程仓库的根目录。该目录需要是一个已克隆的 Git 仓库。
3. 如果需要使用同步功能，请先在电脑上安装并登录 GitHub CLI：

   ```bash
   gh auth login
   ```

4. 点击 `Sync All`，即可依次同步、更新本地内容并扫描待办。

## 使用说明

### 手动添加

在左侧输入待办内容，按回车或点击“添加”。未完成事项会始终排在列表最上方；完成后仍可保留，点击文字即可删除。

### 自动扫描

右侧展示由课程仓库扫描出的待办。应用会检查仓库中的一级作业目录：若目录中还没有常见的作业提交文件，就会生成一条待办。你可以完成、拖动排序，或将不需要的结果加入黑名单；被忽略的项目不会在之后的扫描中再次出现。

### 同步仓库

- `Run gh sync`：同步 GitHub 上的课程 fork。
- `Pull Local`：将远端更新拉取到本地。
- `Scan`：仅重新检查本地作业目录。
- `Sync All`：按上述顺序完成整套流程。

执行后的结果会显示在 Monitor 中，方便了解每个仓库是否成功完成操作。

> 建议在同步前先处理自己已知的 Git 冲突。遇到无法自动处理的情况，应用会显示具体结果，便于你自行检查。

## 反馈

如果扫描结果、同步过程或任务列表不符合预期，请记录 Monitor 中显示的结果，并附上复现步骤后再反馈；这会更容易定位问题。
